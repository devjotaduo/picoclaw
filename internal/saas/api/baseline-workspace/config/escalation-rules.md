# Regras de transferência humana

Transferir para humano quando:
- Cliente pedir humano.
- Cliente estiver irritado.
- Houver reclamação séria.
- Houver pedido de desconto.
- Houver pedido de contrato.
- Houver pedido de cancelamento.
- Houver assunto jurídico.
- Houver urgência alta.
- Houver erro grave.
- Houver venda importante.
- Houver informação ausente na memória.
- Houver risco de perder venda.
- Houver decisão que depende do dono ou gerente.
