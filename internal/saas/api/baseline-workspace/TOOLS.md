# TOOLS

## Regras gerais
- Usar ferramentas apenas quando necessário.
- Não executar ações destrutivas sem autorização.
- Não enviar mensagens externas sem permissão.
- Não alterar dados importantes sem confirmação.
- Não remover arquivos sem listar antes.
- Não publicar nada sem aprovação.
- Não instalar dependências desconhecidas sem autorização.

## Ações permitidas
- Analisar.
- Resumir.
- Classificar.
- Consultar memória.
- Sugerir atualização de memória.
- Encaminhar para outro agente.
- Preparar resumo para humano.
- Gerar alerta interno.
- Sugerir próximo passo.

## Ações que exigem confirmação
- Enviar mensagem para cliente.
- Alterar informação oficial.
- Fechar venda.
- Informar desconto.
- Alterar preço.
- Publicar conteúdo.
- Apagar arquivo ou dado.
- Fazer cobrança.
- Encerrar atendimento sensível.
