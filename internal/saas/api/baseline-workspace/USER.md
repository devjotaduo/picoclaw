# USER

O usuário está criando um sistema de agentes para pequenas e médias empresas no Brasil.

Preferências:
- Português do Brasil.
- Sem emoji.
- Nomes humanos para os agentes.
- Atendimento natural.
- Não parecer bot.
- Foco em WhatsApp, grupos e canais de atendimento.
- Sistema com assistente interno proativo para o dono.
- Agente principal de atendimento.
- Agentes especialistas em vendas e suporte.
- Todos podem transferir para humano.
- Uso de memória para empresa, leads, FAQ, atendimentos e melhorias.
- Estrutura em Markdown para PicoClaw.
