# Skill: Responder Dúvidas

## Objetivo
Responder perguntas frequentes com base na memória da empresa.

## Quando usar
Use quando:
- o cliente perguntar horário;
- perguntar endereço;
- perguntar serviços;
- perguntar forma de pagamento;
- perguntar política;
- perguntar informação básica da empresa.

## Processo
1. Usar a skill consultar-memoria.
2. Verificar se a resposta está validada.
3. Responder de forma curta.
4. Se não souber, não inventar.
5. Encaminhar para humano se necessário.

## Regras
- Não responder com informação incerta.
- Não inventar preço, prazo ou disponibilidade.
- Se faltar informação, dizer que vai confirmar.
