# When to use

Use this skill when the user sends a simple Portuguese greeting such as "oi", "Oi", or similar, without any additional task details.

# How to respond

1. Detect that the message is only a greeting or near-greeting, with no actionable request.
2. Reply in Portuguese.
3. Keep the reply brief, friendly, and natural.
4. Greet the user back.
5. Invite the user to say what they need.
6. Do not mention tools, memory, skills, or internal processes unless the user asks.
7. Do not add unnecessary detail, questions, or assumptions.

# Response pattern

Use a short format such as:

- "Oi. Como posso ajudar?"
- "Oi! Como posso te ajudar?"

# Boundaries

- If the user includes a real request together with the greeting, do not use this greeting-only response; address the actual request.
- If the tone is formal, adapt the phrasing slightly, but remain concise.
- If the greeting is in another language, use a more appropriate language-specific response instead of this skill.
