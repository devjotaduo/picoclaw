# Skill: Resumo para Humano

## Objetivo
Evitar que o cliente precise repetir informações ao ser transferido.

## Quando usar
Use antes de qualquer transferência humana.

## Processo
1. Resumir o caso.
2. Listar dados coletados.
3. Informar o que já foi respondido.
4. Indicar risco e urgência.
5. Sugerir próximo passo.
