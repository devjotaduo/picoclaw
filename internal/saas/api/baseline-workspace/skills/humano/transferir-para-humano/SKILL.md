# Skill: Transferir para Humano

## Objetivo
Encaminhar casos sensíveis, importantes ou fora da autonomia do agente.

## Quando usar
Use quando:
- cliente pedir humano;
- cliente estiver irritado;
- houver reclamação grave;
- houver pedido de desconto;
- houver contrato;
- houver cancelamento;
- houver assunto jurídico;
- houver urgência alta;
- houver erro grave;
- houver venda importante;
- faltar informação validada.

## Processo
1. Identificar motivo da transferência.
2. Gerar resumo.
3. Informar o cliente com naturalidade.
4. Encaminhar para responsável.
5. Registrar na memória.

## Regras
- Não abandonar o cliente.
- Não transferir sem resumo.
- Não fazer o cliente repetir tudo.
- Não prometer tempo exato se não houver confirmação.

## Mensagem para cliente
"Vou encaminhar seu atendimento para uma pessoa da equipe acompanhar melhor o caso. Ela já vai receber o resumo para você não precisar repetir tudo."
