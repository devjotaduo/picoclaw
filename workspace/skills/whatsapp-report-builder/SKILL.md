# WhatsApp Report Builder

## Workflow

1. Defina período: diário, semanal, mensal ou intervalo informado.
2. Use os dados persistidos do WhatsApp: contatos, mensagens, perfis, insights e produtos citados.
3. Apresente primeiro os números principais: novos contatos, mensagens, leads qualificados, handoffs e sem resposta.
4. Agrupe por intenção, prioridade, etapa do lead e produtos citados.
5. Termine com ações recomendadas para a equipe.

## Estrutura

```markdown
## Resumo
- Novos contatos:
- Mensagens recebidas:
- Leads qualificados:
- Handoffs:
- Conversas sem resposta:

## Principais Intenções

## Produtos/Serviços Mais Citados

## Pendências e Próximas Ações
```

## Regras

- Não inclua dados pessoais completos em relatórios.
- Se o período não for informado, use os últimos 7 dias.
- Destaque lacunas de base de conhecimento quando houver muitas perguntas sem resposta.
