# Skill: Classificar Lead

## Objetivo
Classificar o interesse comercial do cliente.

## Quando usar
Use quando:
- cliente pedir preço;
- cliente pedir proposta;
- cliente perguntar prazo;
- cliente demonstrar interesse;
- cliente pedir reunião;
- cliente estiver comparando opções.

## Processo
1. Identificar necessidade.
2. Identificar urgência.
3. Identificar orçamento, se possível.
4. Identificar poder de decisão.
5. Classificar como frio, morno ou quente.
6. Registrar próximo passo.

## Regras
- Não pressionar o cliente.
- Não forçar classificação.
- Se faltar informação, classificar como pendente.
- Lead quente deve gerar alerta para Rafael ou humano.
