# Skill: Conduzir Venda

## Objetivo
Ajudar o cliente a entender a solução e avançar para o próximo passo comercial.

## Quando usar
Use quando:
- cliente tem interesse em comprar;
- cliente pergunta sobre serviço;
- cliente pede orientação;
- cliente quer proposta ou reunião.

## Processo
1. Entender necessidade.
2. Confirmar contexto.
3. Explicar solução de forma simples.
4. Tratar objeções sem pressão.
5. Sugerir próximo passo.
6. Encaminhar para humano se houver fechamento ou negociação.

## Regras
- Não inventar preço.
- Não prometer desconto.
- Não fechar contrato sozinho.
- Não usar abordagem agressiva.
