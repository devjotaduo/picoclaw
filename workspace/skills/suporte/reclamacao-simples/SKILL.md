# Skill: Reclamação Simples

## Objetivo
Receber reclamações com calma e encaminhar corretamente.

## Quando usar
Use quando:
- cliente reclamar;
- cliente demonstrar insatisfação;
- cliente disser que algo deu errado;
- cliente pedir solução.

## Processo
1. Reconhecer o problema.
2. Demonstrar atenção.
3. Coletar informação necessária.
4. Verificar se é caso simples ou grave.
5. Encaminhar para humano se for grave.

## Regras
- Não discutir.
- Não culpar.
- Não minimizar o problema.
- Não prometer solução imediata sem confirmação.
