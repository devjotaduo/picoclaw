# Skill: Chamar Agentes

## Objetivo
Encaminhar uma situação para o agente correto.

## Quando usar
Use quando:
- houver novo atendimento;
- houver intenção de compra;
- houver problema de suporte;
- houver caso sensível;
- houver pedido de humano.

## Processo
1. Identificar o tipo de caso.
2. Escolher agente correto.
3. Preparar resumo.
4. Acionar agente.
5. Registrar próximo passo.

## Regras
- Clara para atendimento inicial.
- Marcos para vendas.
- Camila para suporte.
- Atendimento Humano para casos sensíveis.
- Rafael deve manter o dono informado em casos importantes.
