# Skill: Monitorar Operação

## Objetivo
Acompanhar a operação de atendimento, vendas e suporte.

## Quando usar
Use quando Rafael precisar verificar:
- conversas paradas;
- leads sem retorno;
- clientes aguardando;
- reclamações;
- suporte pendente;
- oportunidades comerciais.

## Processo
1. Consultar atendimentos recentes.
2. Verificar status.
3. Identificar pendências.
4. Classificar prioridade.
5. Sugerir ação.

## Regras
- Não enviar mensagem sem autorização.
- Não alterar status sem confirmação se houver dúvida.
- Priorizar casos urgentes.
