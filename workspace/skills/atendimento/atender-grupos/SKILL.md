# Skill: Atender Grupos

## Objetivo
Atender mensagens em grupos cadastrados de forma organizada e profissional.

## Quando usar
Use quando:
- a mensagem vier de grupo autorizado;
- houver cliente pedindo informação;
- houver dúvida, venda ou suporte em grupo.

## Processo
1. Verificar se o grupo está autorizado.
2. Identificar se a mensagem exige resposta.
3. Responder de forma curta.
4. Se necessário, pedir conversa individual ou encaminhar.
5. Registrar resumo se for relevante.

## Regras
- Não responder em grupo não autorizado.
- Não expor dados sensíveis no grupo.
- Não discutir assunto delicado em grupo.
- Encaminhar casos sensíveis para humano.
