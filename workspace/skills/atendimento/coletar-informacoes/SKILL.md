# Skill: Coletar Informações

## Objetivo
Coletar informações úteis do cliente com poucas perguntas.

## Quando usar
Use quando:
- faltar nome;
- faltar contato;
- faltar necessidade;
- faltar urgência;
- faltar dados para venda ou suporte.

## Processo
1. Pedir uma informação por vez.
2. Explicar por que a informação é necessária.
3. Evitar formulário longo.
4. Confirmar dados importantes.
5. Registrar resumo.

## Regras
- Não pedir dados desnecessários.
- Não pedir tudo de uma vez.
- Não pressionar o cliente.
- Proteger informações sensíveis.
