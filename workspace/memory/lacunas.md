# Lacunas de conhecimento

Toda vez que um agente é perguntado sobre algo que não está na base (`memory/empresa.md`, `memory/faq.md`, `memory/marca.md`, etc.) e precisa improvisar ou pedir para o cliente esperar, registra a lacuna aqui. O dono revisa periodicamente e responde, fechando a lacuna.
